# Кейс 4. «Записи с сайта не создаются, ошибка 500»

**Тикеты #125, #126** · Тату-студия «Ink», Фотостудия «Кадр» · integration · priority: urgent / high

> Клиенты пишут, что не могут записаться через сайт, виджет показывает ошибку.

## Расследование
Два похожих тикета за 10 минут — проверяю, не общий ли это сбой. Запрос [`04_api_errors_by_window.sql`](../queries/04_api_errors_by_window.sql) — ошибки 5xx по эндпоинтам в 30-минутных окнах:

```
   endpoint   |    window_start     | errors_5xx | affected_customers | avg_latency_ms
--------------+---------------------+------------+--------------------+----------------
 /v1/bookings | 2026-11-10 14:00:00 |         60 |                 18 |           5346
```

Вывод: массовый инцидент — 60 ошибок 500 у 18 клиентов за полчаса на одном эндпоинте, среднее время ответа — 5,3 с вместо обычных 40–400 мс. Проблема не у клиентов, а у нас. Оба тикета привязываю к одному инциденту.

## Ответ клиентам
> Здравствуйте! Сегодня с 14:00 у части клиентов не создавались онлайн-записи — это сбой на нашей стороне, ваши настройки в порядке. Команда разработки уже занимается исправлением.
>
> Я сообщу вам, как только запись снова заработает. Записи, которые клиенты не смогли оформить, к сожалению, не сохранились — если есть возможность, предложите им записаться повторно чуть позже.
