# Кейс 3. «Мой аккаунт заблокирован, я ничего не делал»

**Тикет #3090** · клиент u0088 · priority: normal

> «Утром не могу войти — пишет, что аккаунт заблокирован. Пароль я не менял».

## Расследование
```bash
$ python triage.py bruteforce
  ip=185.220.101.47  failures=37  max_in_window=37  users=['u0088']  first=03:10:00  last=03:14:12

$ jq -c 'select(.user == "u0088" and .level != "INFO")' logs/app.log
{"ts":"2026-11-20T03:14:21","level":"WARN","msg":"account locked","reason":"too many failed logins"}
```

Вывод: ночью с 03:10 до 03:14 с одного внешнего IP было 37 неудачных попыток входа, и только в этот аккаунт. Похоже на подбор пароля. Защита сработала правильно: аккаунт заблокировался, успешного входа с этого IP не было. Клиент сам ничего не нарушал.

## Ответ клиенту
> Здравствуйте! Ваш аккаунт заблокировала наша система защиты: сегодня ночью кто-то пытался подобрать к нему пароль, 37 попыток с чужого адреса. Войти у него не получилось. Чтобы разблокировать аккаунт, восстановите пароль по ссылке «Забыли пароль?» — придумайте новый, который вы не используете на других сайтах. После этого вход заработает сразу.

## Эскалация (Jira)
**SEC · Подбор пароля к u0088 с 185.220.101.47**
- Тип: Security · Приоритет: Medium
- 37 неудачных входов за 4 минуты, затем автоматическая блокировка. Компрометации нет.
- Предложение: добавить IP в блок-лист на WAF; рассмотреть капчу после 5 неудачных попыток с одного IP.
