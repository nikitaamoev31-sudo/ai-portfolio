# ИИ-администратор салона красоты

Бот в Telegram, который общается с клиентами салона как живой администратор:

- отвечает про услуги, цены, мастеров, адрес и правила;
- подбирает свободное время и **записывает** клиента;
- показывает записи клиента, **переносит** и **отменяет** их;
- за сутки **напоминает** о визите;
- шлёт администратору уведомления о новых записях, отменах и переносах;
- передаёт человеку жалобы, медицинские вопросы, скидки и всё непонятное.

Работает в двух режимах:
- **demo** — тестовый салон «Лаванда» (`salon_demo.json`), записи хранятся в `bookings.json`. Для показа клиентам и съёмки видео.
- **yclients** — реальный салон: услуги, мастера и свободное время берутся из YCLIENTS, записи сразу попадают в журнал.

## Быстрый старт (5 минут)

```bash
cd ai_salon_admin
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

В `.env` впишите `GEMINI_API_KEY` — ключ бесплатно берётся на aistudio.google.com.

**Проверка в терминале** (без Telegram):
```bash
python bot.py --cli
```
Попробуйте: «Хочу на маникюр завтра», «Сколько стоит окрашивание?», «Перенесите мою запись на 16:00», «Можно скидку?».

**Запуск в Telegram:**
1. В @BotFather создайте бота → вставьте токен в `TELEGRAM_BOT_TOKEN`.
2. `python bot.py`
3. Напишите боту `/id`, скопируйте число в `ADMIN_CHAT_ID`, перезапустите — уведомления начнут приходить вам.

## Подключение реального салона (YCLIENTS)

1. Получите партнёрский токен в кабинете разработчика YCLIENTS и ID филиала (компании).
2. В `.env`: `BACKEND="yclients"`, `YCLIENTS_PARTNER_TOKEN`, `YCLIENTS_COMPANY_ID`.
3. Запустите `python bot.py --cli` и проверьте: список услуг → свободное время → тестовая запись → запись видна в журнале YCLIENTS → удалите её вручную.

Важно: адаптер YCLIENTS написан по публичному API онлайн-записи, но **ещё не проверен на живом аккаунте**. Перед первым клиентом обязательно сделайте тестовую запись. Отмену и перенос в режиме YCLIENTS бот пока передаёт администратору.

## Настройка под салон (demo-режим)

Всё в `salon_demo.json`: название, адрес, часы работы, выходные (`days_off`: 0 — понедельник … 6 — воскресенье), шаг слотов, правила, услуги (цена, длительность), мастера и какие услуги они делают.

## Что приходит администратору

- ✅ Новая запись: услуга, мастер, время, имя, телефон
- ❌ Отмена · 🔁 Перенос
- 🙋 Нужен человек — с причиной и chat_id клиента
- ⚠️ Техническая ошибка

## Ограничения демо-версии

- Хранение в JSON-файлах — для 1 салона и демо этого достаточно; для 10+ салонов перейти на базу данных.
- Голосовые сообщения и фото бот не понимает (отвечает только на текст).
- Нужен постоянно работающий компьютер или сервер (VPS от ~5 $/мес) — бот работает, пока запущен `bot.py`.
- Персональные данные клиентов (имя, телефон) хранятся у вас: заключите с салоном договор и согласуйте политику обработки данных.
