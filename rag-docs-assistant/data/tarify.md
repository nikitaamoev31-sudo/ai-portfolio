# Тарифы CloudDesk

CloudDesk — вымышленный сервис онлайн-бухгалтерии для малого бизнеса (демо-данные).

## Тариф «Старт»
Стоимость — 990 рублей в месяц. До 50 операций в месяц, один пользователь, выгрузка отчётов в Excel.

## Тариф «Бизнес»
Стоимость — 2 490 рублей в месяц. Безлимитные операции, до 5 пользователей, интеграция с банками и 1С, приоритетная поддержка.

## Тариф «Корпорация»
Цена рассчитывается индивидуально. Неограниченное число пользователей, персональный менеджер, SLA 99,9%.

## Скидки
При оплате за год — скидка 20%. Для некоммерческих организаций — скидка 30% по запросу.
