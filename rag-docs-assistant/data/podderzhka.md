# Поддержка и возврат

## Часы работы поддержки
Поддержка работает по будням с 9:00 до 21:00 по московскому времени. В выходные отвечаем только клиентам тарифа «Бизнес» и выше.

## Каналы связи
Чат в личном кабинете, почта support@clouddesk.example и Telegram-бот.

## Возврат денег
Деньги за неиспользованный период можно вернуть в течение 14 дней после оплаты. Для возврата напишите в поддержку номер счёта. Деньги поступают на карту за 5–10 рабочих дней.
